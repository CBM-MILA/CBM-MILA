# 🔴⚪ شباب ميلة · CBM Mila 1936

المنصة الرقمية الرسمية لمناصري **النادي الرياضي لبلدية ميلة (CBM 1936)** لموسم 2026/2027 (رابطة ما بين الجهات — مجموعة الشرق).

## 🌐 رابط المنصة المباشر
👉 **[زيارة المنصة الرسمية لشباب ميلة](https://cbm-mila.github.io/CBM-MILA/)**

## 📋 أبرز مميزات المنصة المطوّرة
* 🎫 **بطاقة المناصر الرقمية الرسمية**: إصدار فوري، استعادة بالاسم والرقم، وتوليد بطاقة عالية الدقة (PNG) مزودة برمز QR للتحقق الفوري من الصلاحية.
* ⚽ **مركز المباريات والملعب التكتيكي**: متابعة كافة الجولات (1–30)، أحداث المباريات الدقيقة، التشكيلتين الأساسية والاحتياطية، ورسم تكتيكي لملعب التشكيلة الأساسية.
* 🗳️ **توقعات الجماهير والمواجهات المباشرة (Head-to-Head)**: التصويت على نتيجة المباراة القادمة، واستعراض سجل مواجهات شباب ميلة ضد أي نادٍ في المجموعة.
* 📊 **جدول الترتيب الكامل وإحصائيات البطولة**: عرض الـ 10 أعمدة الكاملة للترتيب، احتساب خصم النقاط تلقائياً، وإحصائيات أقوى هجوم وأقوى دفاع.
* 👕 **بطاقات اللاعبين وسجل المشاركات**: بحث وفرز فوري للاعبين حسب المركز أو الأهداف أو الدقائق، مع ملف تفصيلي لكل لاعب.
* 🤖 **تحديث آلي عبر GitHub Actions (`scraper.py`)**: فحص دوري لموقع الرابطة (`lirf.dz`) وإشعارات تليغرام فورية للنتائج والمناصرين الجدد.
* 📲 **تطبيق ويب تقدمي (PWA)**: قابل للتثبيت على هواتف Android و iOS ويعمل بكفاءة حتى بدون اتصال بالإنترنت.
